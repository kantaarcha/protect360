# PROTECT360

For OIC final case.

Web application for personal financial protection planning, built with React 19 and Vite.

## Modules
- **Overview Dashboard** (`src/pages/OverviewDashboard.jsx`) — Round 1 complete
- **AutoKey** (`src/pages/AutoKey.jsx`) — Smart cashflow tracking
- **Risk Analysis** (`src/pages/RiskAnalysis.jsx`) — Risk assessment & coverage gap analysis
- **Invest (IRR)** (`src/pages/Invest.jsx`) — Return & IRR comparison
- **Game** (`src/pages/Game.jsx`) — Risk management simulator
- **Learning Center** (`src/pages/LearningCenter.jsx`) — Financial & insurance knowledge hub
- **Landing & About** (`src/pages/LandingAbout.jsx`) — Project overview & OIC context

## Development

```bash
npm install
npm run dev
```

## Build & Lint

```bash
npm run lint
npm run build
```
